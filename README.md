## reflectie week 2

In week 2 heb ik mijn illustratie in Figma afgerond en deze als SVG in mijn website gezet. Ik heb geleerd hoe je losse elementen kunt animeren met classes en id’s. Daarnaast heb ik een workshop gevolgd over basishygiëne en geleerd hoe je je code netjes schrijft en herhaling voorkomt. Ik heb light/dark mode toegevoegd met JavaScript en mezelf uit de API gehaald.

Wat lastig was: JavaScript vind ik nog erg moeilijk en het ophalen van data via de API is nog niet helemaal gelukt. Ook merk ik dat ik moeite heb om overzicht te houden in mijn documenten en dat mijn code netter kan.

Conclusie: Deze week heb ik veel geleerd over animaties, code structuur en het gebruik van JavaScript, maar ik merk dat ik nog beter moet plannen en mijn documenten overzichtelijker moet houden. Dit is iets waar ik in de komende weken extra op wil letten.


# Verbetering Herkansing
Voor mijn herkansing heb ik feedback gevraagd van klasgenoten om mijn website te verbeteren. Ze gaven aan dat de website leuk is door de illustratie, maar dat het contrast in light mode iets beter kon, de API-filter werkte nog niet en het was nog niet helemaal duidelijk wat de bedoeling was. 
Nadat ik mijn idee had uitgelegd, werd mijn illustratie duidelijk en mijn API moest ik alleen nog werkend maken.

Ik heb het contrast in light mode verbeterd met kleur/schaduw zodat alles beter leesbaar is. De API werkt nu goed: je kunt filteren op hobby, kleur, dier en seizoen,en als je op “Zoek” klikt, zie je klasgenoten met dezelfde antwoorden die van mij. De resultaten zijn nu beter zichtbaar met een duidelijk grid.

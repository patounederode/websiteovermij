# Verbetering Herkansing
Voor mijn herkansing heb ik feedback gevraagd van klasgenoten om mijn website te verbeteren. Ze gaven aan dat de website leuk is door de illustratie, maar dat het contrast in light mode iets beter kon, de API-filter werkte nog niet en het was nog niet helemaal duidelijk wat de bedoeling was. Nadat ik mijn idee had uitgelegd, werd mijn illustratie duidelijk en mijn API moest ik alleen nog werkend maken. Ik heb het contrast in light mode verbeterd met kleur/schaduw zodat alles iets beter leesbaar is. 

De API werkt nu: je kunt filteren op hobby, kleur, dier en seizoen,en als je op “Zoek” klikt, zie je klasgenoten met dezelfde antwoorden die van mij. De resultaten zijn nu beter zichtbaar met een duidelijk grid.
